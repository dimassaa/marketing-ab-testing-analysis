# Полный цикл A/B-тестирования с расчетом мощности и размера выборки

**Цель:** Провести анализ эксперимента, имитируя работу продуктового аналитика в реальной компании.

**Демонстрируемые навыки:**
- Проверка гипотез (t-критерий, z-критерий для пропорций), p-value, ошибки I/II рода.
- Расчет размера выборки и мощности теста *до* начала анализа.
- Размер эффекта (Cohen’s d, Cohen’s h, относительный прирост) и его интерпретация.
- Доверительные интервалы для разности средних и пропорций.
- Бизнес-метрики: конверсия, ARPU, влияние на выручку.

## Зафиксированные решения (Q&A, 2026-09-21)

1. **Датасет:** Marketing A/B Testing (ad vs psa), файл `data/marketing_AB.csv` (скачан вручную, в репозитории).
2. **MDE:** +0.5 п.п. (≈ +20% относительного прироста при базовой конверсии ~2.5%). Мотивация: план изначально предлагал +2 п.п. (~+80% отн.), что делает power-анализ тривиальным на 588K строках.
3. **Язык:** комментарии кода и итоговые артефакты — английский; объяснения в чате — русский с англ. терминами.
4. **Тесты:** `src/` покрывается pytest.
5. **Отчёт:** HTML (экспорт ноутбука через jupyter nbconvert) в `reports/`.
6. **Корень репозитория:** `/mnt/d/opencode/new18` (структура плана прямо в этой папке).
7. **Глубина:** 7 шагов изначального плана + power-кривая «размер выборки → мощность» + анализ чувствительности к MDE.
8. **Обучение:** каждое объяснение дублируется в `notes/` (см. AGENTS.md).

## Что сделать

1. **Этап 1 — Данные и EDA:** целостность (data integrity): строки, дубликаты user id, пропуски, типы, диапазоны, sanity checks; распределение конверсий, состав групп ad/psa, выбросы. Решить вопрос единицы анализа.
2. **Этап 2 — Pre-registration:** сформулировать H₀ и H₁, зафиксировать α=0.05, мощность 80%, направленность теста (двусторонний), MDE +0.5 п.п. ДО анализа результатов.
3. **Этап 3 — `src/`:** функции расчёта размера выборки, мощности, z-теста для пропорций, CI для разности, Cohen’s h/d, power-кривой; pytest.
4. **Этап 4 — Power-анализ:** необходимый размер выборки для MDE +0.5 п.п.; power-кривая; чувствительность к MDE (0.1–1.0 п.п.).
5. **Этап 5 — Тест:** проверка допущений; z-тест для пропорций; доверительный интервал для разности конверсий; статистическая и практическая значимость.
6. **Этап 6 — Бизнес-значимость:** относительный прирост, оценка влияния на выручку/ARPU (с оговорками о прокси), интерпретация CI в бизнес-терминах.
7. **Этап 7 — Вывод:** решение «внедрять / не внедрять» с границами интерпретации (ассоциация vs причинность); README; HTML-отчёт в `reports/`.
