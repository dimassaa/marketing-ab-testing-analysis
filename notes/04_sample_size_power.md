# Этап 4 — Размер выборки, power-кривая и чувствительность

## Цель этапа

По pre-registered параметрам вычислить необходимый объём выборки на группу, показать визуально зависимость «n → мощность» (power curve) и «MDE → n» (sensitivity analysis).

## Зачем это важно

Одно единственное число размера выборки легко «проскочить», не поняв логики. Power-кривая отвечает на вопрос «сколько данных покупает сколько мощности?» — она объясняет, ПОЧЕМУ n таково. Анализ чувствительности отвечает «а если захотели бы уловить эффект меньше/больше — сколько данных бы понадобилось?» и показывает границы применимости данного датасета. Это два стандартных deliverable продуктового аналитика при планировании эксперимента.

## Параметры (зафиксированы на этапе 2)

p₀ = 0.0179 (baseline psa, фактический контроль), MDE = +0.005, α = 0.05 двустороннее, мощность = 0.80.

## Результаты

- Требуемый n на группу: **12 547**.
- Фактическая минимальная группа psa: 23 524 (12 547 ≤ 23 524 → тест спроектирован адекватно).
- Достигнутая мощность при n = 23 524: **0.97** (мы закладывали 0.80).
- Cohen's h = 0.035 — «малый» эффект (designed small MDE).
- Чувствительность к MDE:

| MDE, п.п. | n на группу |
|---|---|
| 0.1 | 283 523 |
| 0.2 | 72 769 |
| 0.3 | 33 180 |
| 0.5 | 12 547 |
| 1.0 | 3 512 |

## Интерпретация (важно для резюме)

- Мощность 0.97 на фактическом минимуме означает: если реальный эффект ≥ MDE, тест почти наверняка его увидит. Недостатка мощности (underpower) нет.
- Но данные НЕ позволяют уловить «игрушечные» эффекты (<0.2 п.п.): для них нужны десятки/сотни тысяч на группу. Это ограничение фиксируется честно.
- Ключевое различие: способность ОБНАРУЖИТЬ эффект (resolvability) ≠ БИЗНЕС-ценность эффекта (practical significance). Это разведение — главная тема этапов 5–6.

## Подводные камни

1. Считать размер выборки при равных группах, а фактические группы 96/4 — вывод про мощность будет завышен. Здесь спасает «узкое горло» (bottleneck) — меньшая группа.
2. Путать MDE и наблюдаемый эффект: MDE — это плановая величина «что хотим уловить», наблюдаемый эффект выясняется только после теста.
3. Power-кривая не должна быть «украшательством»; она обязана нести маркеры принятых решений (n*, psa-group), иначе она неинформативна.
