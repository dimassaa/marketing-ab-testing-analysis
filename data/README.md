# Data

Source dataset: **Marketing A/B Testing** (Kaggle, faviovaz/vaz/marketing-ab-testing).

- File: `marketing_AB.csv` (~22 MB, 588,101 rows).
- Schema: `user id`, `test group` (`ad` | `psa`), `converted` (0/1),
  `total ads`, `most ads day`, `most ads hour`.

Original page:
`https://www.kaggle.com/datasets/faviovaz/marketing-ab-testing`

Re-download: use the Kaggle download button (the CSV needs no authentication
for direct download from the dataset page's "Data" tab).
